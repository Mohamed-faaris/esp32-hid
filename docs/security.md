# Security and privacy

## Device API
Protected routes use a bearer secret from ESP32_API_SECRET in the root .env. Firmware secrets are generated into an ignored header. Firmware HTTP is not encrypted; keep the device on a trusted isolated LAN and do not port-forward it.

## MCP
The MCP HTTP transport binds to 127.0.0.1 by default, requires MCP_AUTH_TOKEN, and validates Host and Origin. Do not bind publicly without a TLS/auth gateway. Stdio mode is intended for local agent hosts.

## Web
The ESP32 API URL is server-side only. The operator enters the device secret in the web session. Never expose secrets through NEXT_PUBLIC variables.

## Telemetry
Only HTTPS endpoints are accepted; TLS certificate validation stays enabled. Event queue and retry count are bounded. The queue is RAM-only and does not survive a reboot. Never transmit raw typed text, macro bodies, API secrets or Wi-Fi credentials.

## Recording
Recording starts only after explicit user action and stores commands generated by this ESP32 controller. It is not a host-side keylogger.

## HID safety
No stealth, detection bypass or covert key capture is implemented. Mouse deltas are bounded. STOP releases all active keyboard/mouse state.
